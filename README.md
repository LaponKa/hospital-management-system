## Features
-  Admin authentication system
-  Doctor management (CRUD operations)
-  Patient management with family grouping
-  Management reports with data visualization
-  Data persistence (file I/O)
-  GUI for report viewing

## Technologies
- Python 3.x
- OOP (Inheritance, Polymorphism)
- GUI Framework
- Matplotlib (for data visualization)

## Project Structure
- `Admin.py` - Main administration class with login and management functions
- `Doctor.py` - Doctor class with patient assignment
- `Patient.py` - Patient class with symptoms tracking
- `main.py` - Entry point with menu system

## Testing
Comprehensive test suite with 10 test cases covering:
- User authentication
- Doctor registration/update/deletion
- Patient discharge and assignment
- Report generation
- GUI functionality

- Admin Login workflow

## How to Run
1. Ensure Python 3.x is installed
2. Run `python main.py`
3. Login with default credentials: admin / 123
